# 🌊 SDG 14: Life Below Water - Awareness Portal

## 📌 Project Overview
This project is an interactive, educational website dedicated to promoting the United Nations Sustainable Development Goal 14: **Life Below Water**. Our goal is to raise awareness about marine conservation, the impact of ocean pollution, and the importance of preserving aquatic ecosystems for future generations. 

The website provides users with engaging information, actionable conservation steps, and visual insights into the current state of our oceans.

## 🛠️ Technologies Used
This project was built from scratch using core web technologies without relying on heavy external frameworks:
*   **HTML5:** For semantic and accessible page structure.
*   **CSS3:** For responsive design, custom styling, and layout management using standard CSS rules.
*   **JavaScript (Vanilla):** For DOM manipulation, interactive components, and smooth user experiences.
